## Features

- Movable/Draggable AppWindows
- Resizable AppWindow
- Chat Based Portfolio System
- Action Based Chat Unlock System

## Tech Stack

- Tanstack Start
- Zustand
- Immer
- Tailwind CSS
- Better Auth, Prisma, and Zod (Not USED Though)

## How to Contribute?

Step 1:
```bash
git clone https://github.com/mr67creative/isitpossible.git
```
Step 2:
```bash
npm i
```
Step 3 & 4: (Skippable)
```bash
npm run db:generate
```
```bash
npm run db:push
```
Step 5:
```bash
npm run dev
```
