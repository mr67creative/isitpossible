## Why it exists?

It serves as a (somewhat) unique way to access my details (just like a portfolio would do). 

## How is it different?

It is built to look like an OS + a chatting interface for a unique way to access various information.

## Features

- Movable/Draggable AppWindows
- Resizable AppWindow
- Chat Based Portfolio System
- Action Based Chat Unlock System

## Tech Stack

- Tanstack Start
- Zustand
- Immer
- Tailwind CSS
- Better Auth, Prisma, and Zod (Not USED Though)

## How to Contribute?

Step 1:
```bash
git clone https://github.com/mr67creative/isitpossible.git
```
Step 2:
```bash
npm i
```
Step 3 & 4: (Skippable)
```bash
npm run db:generate
```
```bash
npm run db:push
```
Step 5:
```bash
npm run dev
```
